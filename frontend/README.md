# Frontend

Aplicação Next.js/React responsável pela interface gerencial.

```text
app/page.tsx             Dashboard executivo
app/catalogo/page.tsx    Catálogo técnico
app/financeiro/page.tsx  Indicadores financeiros
app/frota/page.tsx       Operação e manutenção
components/              componentes interativos compartilhados
```

O frontend apresenta cálculos recebidos da API; regras financeiras permanecem no backend.
